SMS Opt-In

This page describes how Duezly collects SMS consent and the exact opt-in language shown to users during enrollment.

Program Overview

Service name

Duezly — automated daily SMS homework reminders for Canvas LMS users.

Sender number

+1 (678) 578-2152 — all messages are sent from this number.

Message type

Recurring automated SMS notifications — approximately 1 message per day while enrolled, containing a summary of assignments and due dates pulled from the user's Canvas calendar feed.

Consent to receive SMS messages is not a condition of purchase or use of any Duezly service.

STOP / HELP keywords

  • STOP — immediately unsubscribes the number; one confirmation message is sent and no further messages follow.
  • HELP — replies with support contact info (hello@duezly.com).

Message & data rates

Standard message and data rates from the user's mobile carrier may apply.

How Opt-In Is Collected

SMS consent is collected on the dashboard signup card (duezly.com/dashboard.html) — the first screen users see after signing in with Google. The signup card appears at the top of the dashboard for any user who has not yet subscribed. It contains an optional, unchecked SMS consent checkbox. No SMS messages are ever sent without the user checking this box and completing their account setup.

The consent checkbox is presented with a prominent notice explaining that SMS consent is needed to receive reminders. If the user proceeds without checking the box, a gentle warning is shown explaining that texts will not be sent without consent. The checkbox can be enabled at any time from the settings page.
